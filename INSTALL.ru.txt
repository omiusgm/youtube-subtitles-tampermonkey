YouTube — скачать субтитры и текст
Версия 1.0.0 · 24 октября 2026

Это userscript для Tampermonkey в Chrome — того расширения, которое показано на скриншотах.
Главный файл: youtube-subtitles.user.js

УСТАНОВКА

1. Открой youtube-subtitles.user.js в текстовом редакторе или в любом редакторе кода.
   Скопируй ВЕСЬ код, включая верхние строки // ==UserScript==.
2. В Chrome нажми значок Tampermonkey → «Создать новый скрипт…».
3. Удали шаблон из редактора, вставь скопированный код.
4. Сохрани: ⌘S на Mac, Ctrl+S на Windows.
5. Убедись, что новый скрипт включён. Перезагрузи открытую вкладку YouTube.

Другой вариант: Tampermonkey → Панель управления → Утилиты → Импорт из файла → выбери youtube-subtitles.user.js.
Название пункта может отличаться в разных версиях. Не нужно удалять или заменять существующий скрипт скачивания превью.

ИСПОЛЬЗОВАНИЕ

Открой ролик YouTube. Справа внизу появится кнопка «↓ Субтитры».
Выбери язык и формат, затем «↓ Скачать».
Файл поступает в обычные загрузки Chrome; если Chrome спрашивает место сохранения, выбери его.
Имя файла содержит название ролика, ID и язык.

• TXT — текст без таймкодов, с названием, ссылкой и языком в начале.
• TXT с таймкодами — время начала каждого фрагмента.
• SRT — стандартные субтитры для видеоплееров и монтажа.
• VTT — субтитры для веб-плееров.

«Копировать» копирует подготовленный текст. Если браузер запрещает буфер обмена,
скрипт выделяет текст в поле: нажми ⌘C / Ctrl+C самостоятельно.

Если обычное скачивание не получилось:

1. Включи CC на плеере YouTube и выбери нужный язык.
2. Нажми «Обновить список» в меню скрипта и повтори скачивание.
3. Либо раскрой описание ролика → «Показать текст видео».
   Дождись загрузки. В скрипте выбери «Из расшифровки YouTube · язык её панели».
   Для другого языка сначала поменяй его в самой панели расшифровки YouTube.

КАК ЭТО РАБОТАЕТ

Скрипт получает список дорожек текущего видео и скачивает доступные YouTube субтитры.
Для дорожек, которым нужен запрос плеера, использует ответ или адрес запроса самого YouTube.
Во время такой попытки выбранные субтитры могут ненадолго включиться; скрипт пытается
восстановить прежнюю дорожку, если зритель сам не поменял её за это время.

Есть отдельный экспорт полной расшифровки из данных открытой панели YouTube.
Пустой ответ, распознанная неполная расшифровка и ответ от предыдущего видео не сохраняются.
Если у фрагментов расшифровки нет времени окончания, оно определяется по началу следующего;
для последнего такого фрагмента используется длительность 2 секунды.

Скрипт работает на страницах обычных видео, Shorts и записей трансляций.
Для продолжающегося эфира полный экспорт откладывается до завершения и обработки.

ОГРАНИЧЕНИЯ

Это скачивание существующих субтитров, включая автоматические, а не распознавание аудио.
Если YouTube не предоставляет субтитры и расшифровку, скрипту нечего скачать.
Доступность языков и точность текста зависят от YouTube и автора видео.
YouTube меняет внутренние методы: отдельные видео или будущие обновления могут потребовать правки скрипта.

Если кнопки нет: проверь, что скрипт включён, и перезагрузи YouTube.
Если другие userscript тоже не работают, в настройках расширения Tampermonkey в Chrome
проверь «Разрешить пользовательские скрипты» / Allow User Scripts.
Это настройка Chrome; данный файл её автоматически не меняет.
Официальная справка: https://www.tampermonkey.net/faq.php?q=Q209

ДАННЫЕ И ПРОВЕРКА

Нет сторонних библиотек, платных API или стороннего сервера распознавания.
Скрипт работает только на youtube.com; запросы за субтитрами ограничены текущим origin YouTube.
Текст и временные адреса запросов хранятся в памяти вкладки, а не отправляются другому сервису.
При переходе между видео кеш сбрасывается. Сохранение — локальный Blob-файл через Chrome.

Проверены 13 регрессионных тестов преобразования, обработка XML в браузере
и интерфейс/скачивание в Chrome на синтетическом стенде. Это не подтверждение
работоспособности на всех реальных роликах YouTube. Установка выполняется пользователем в Tampermonkey.

Тесты для разработчика: node --test tests/core.test.cjs
Локальный стенд: python3 tests/serve.py — слушает только 127.0.0.1, показывает адрес при запуске.
